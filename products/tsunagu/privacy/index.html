プライバシーポリシー

制定日：2026年10月8日

土田 陽日（以下「運営者」）は、Google スプレッドシート用アドオン「Tsunagu」（以下「本サービス」）における利用者の情報の取扱いについて、個人情報の保護に関する法律その他の関係法令を遵守し、以下のとおり定めます。

1. 取得する情報と取扱い

情報取扱い
Google アカウントのメールアドレス本サービスはアドオン内でメールアドレスから不可逆な識別子（SHA-256 ハッシュ）を作成し、識別子だけを運営者のサーバーへ送信します。メールアドレスそのものを運営者が受け取ったり保存したりすることはありません。識別子は、無料枠の残り枚数とご契約プランの管理にのみ使います。
名刺の画像と読み取り結果「名刺の読み取り」を実行したときだけ、選んだ画像を運営者のサーバーへ送信し、Google Cloud の Vertex AI（Gemini）で文字を読み取ります。画像と読み取り結果はメモリ上で処理し、運営者のサーバーには保存せず、ログにも記録しません。読み取り結果は利用者のスプレッドシートにのみ書き込まれます。
スプレッドシートの内容本サービスは利用者が開いているスプレッドシートにだけアクセスし、各機能の実行に必要な範囲で読み書きします。インボイス確認・入金消込・データ整形はアドオン内で処理し、シートの内容を運営者のサーバーへ送信しません（国税庁の公表サイトでのオンライン確認を利用する場合は、登録番号のみを送信します）。
利用回数識別子ごと・月ごとの名刺の読み取り枚数を、Google Cloud Firestore（東京リージョン）に保存します。保存するのは識別子・年月・枚数のみです。
お問い合わせ・ご意見［ご意見・不具合を送る］で送られた内容（種類・本文・任意で入力されたメールアドレス・画面名・アドオンのバージョン・識別子）を、返信と改善のために運営者が管理するスプレッドシートに保存します。
技術ログ処理時間・エラーの種類・AIの処理量など、名刺やシートの内容を含まない情報を、障害対応と品質改善のために記録します（Google Cloud Logging、保存期間は原則30日）。

2. 利用目的

  1. 本サービスの提供（名刺の読み取り、登録番号の確認等）
  2. 無料枠・ご契約プランの管理と不正利用の防止
  3. お問い合わせへの対応、不具合の調査と改善

取得した情報を広告に利用したり、販売したりすることはありません。名刺の画像や読み取り結果を、AIモデルの学習に利用することはありません。

3. Google API から取得する情報について（Limited Use）

本サービスが Google API から受け取った情報の利用と移転は、Google API サービスのユーザーデータに関するポリシー（Limited Use の要件を含む）に従います。

Tsunagu's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

本サービスが使用する権限は次のとおりです。

  • 現在開いているスプレッドシートの表示・編集（spreadsheets.currentonly）
  • スプレッドシート内でのダイアログ表示（script.container.ui）
  • 外部サービスへの接続（script.external_request）：運営者のサーバーへの送信に使用
  • メールアドレスの参照（userinfo.email）：上記の識別子の作成にのみ使用

運営者は本サービスの提供のため、次の事業者のクラウドサービスを利用しています。

事業者内容

米国の個人情報保護制度については、個人情報保護委員会が公表している外国における個人情報の保護に関する制度等の調査をご参照ください（ベトナムについても同じ資料に掲載されています）。運営者は、委託先との契約により個人情報の適切な取扱いを求めるとともに、Google Cloud の利用規約およびデータ処理に関する規約（Cloud Data Processing Addendum）に基づき、Google LLC による適切な取扱いを確保しています。

法令に基づく場合を除き、利用者の同意なく第三者に情報を提供することはありません。

5. 安全管理措置

  • 通信はすべて暗号化（HTTPS）しています。
  • サーバーへのアクセスには専用の認証キーを使用し、キーはアドオンの利用者からは見えない場所で管理しています。
  • 名刺の画像と読み取り結果は保存せず、ログにも残しません。
  • クラウドの管理権限は必要最小限の担当者に限定しています。

6. 保存期間と削除

  • 利用回数：記録した月の翌月から12か月以内に削除します。
  • お問い合わせ・ご意見：対応完了後、原則2年以内に削除します。
  • 本サービスをアンインストールすると、アドオンはスプレッドシートにアクセスしなくなります。シートに書き込まれた内容は利用者のスプレッドシートに残ります。
